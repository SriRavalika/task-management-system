Task Management System

A backend web application developed using Java and Spring Boot to manage daily tasks efficiently.

Technologies Used

- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Spring Security
- Maven
- REST API

Features

- User Registration
- User Login
- Password Encryption using BCrypt
- Create New Tasks
- View All Tasks
- Delete Tasks
- Task Priority Management
- Task Status Management
- Task Deadline Management
- Exception Handling

Project Structure

- Controller
- Entity
- Repository
- Service
- Exception
- Security Configuration

Database

MySQL

Database Name: "task_management_db"

How to Run the Project

1. Clone this repository.
2. Open the project in Eclipse.
3. Configure MySQL database credentials in "application.properties".
4. Create the database "task_management_db".
5. Run "TaskManagementApplication.java".
6. Access the application through "http://localhost:8080".
